Install Prerequisites

Before we begin, you'll need to install a few tools. These are standard, safe programs used by millions of developers worldwide.

Step 1.1: Install Homebrew (Package Manager)

🔍 What is Homebrew?

Homebrew is like an "App Store" for developer tools on Mac. Instead of downloading installers from websites, you can install programs with simple commands. It's trusted by millions of Mac users.

Open Terminal (press Cmd + Space, type "Terminal", press Enter) and paste this command:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
🔍 What this command does

This downloads and runs the official Homebrew installer script. It will ask for your Mac password (you won't see it as you type - that's normal for security). The installation takes about 5 minutes.

Step 1.2: Install Node.js

🔍 What is Node.js?

Node.js is the "engine" that runs your website on your computer. Think of it like how you need a DVD player to watch a DVD - you need Node.js to run modern websites locally.

After Homebrew finishes, run this command:

brew install node

Step 1.3: Install Git

🔍 What is Git?

Git is a tool for downloading and managing code. It's how we'll download your website files. Every major tech company uses Git.

brew install git

Verify Installation

Let's make sure everything was installed correctly. Open a new terminal and run these commands one at a time:

Check Node.js

node --version
🔍 What you should see

A version number like v20.10.0 or v22.5.0. Any version starting with v18 or higher is good!

Check npm (comes with Node.js)

npm --version
🔍 What you should see

A version number like 10.2.0. npm is the "package manager" that installs website dependencies.

Check Git

git --version
🔍 What you should see

Something like git version 2.42.0. Any version 2.x is fine!

✅ All Good?

If you see version numbers for all three commands, you're ready to continue!

🔧

Troubleshooting - Click if commands don't work

❌ "command not found" or "'node' is not recognized"
Solution 1: Did you close and reopen the terminal after installing? The terminal needs to be restarted to find new programs.
Solution 2: The program might not be in your system PATH. Try reinstalling Node.js/Git and make sure to check any options about "Add to PATH" during installation.
❌ Mac: "zsh: command not found: node"
Solution: Add Node to your shell profile. Run these commands:
echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
❌ Shows an old version
Solution: You might have an older version installed. That's usually fine! If you need to update, reinstall from the download links in Step 1.

Set Up GitHub Account
🔍 What is GitHub?

GitHub is like Google Drive, but for code. It stores your website files online and lets you download them to any computer. It also keeps track of all changes you make, so you can always go back if something breaks.

📋 Create a Free GitHub Account

  1. Go to github.com and click "Sign up"
  2. Enter your email address
  3. Create a password (save this somewhere safe!)
  4. Choose a username (this will be visible, e.g., "tailored-solutions-uk")
  5. Complete the verification puzzle
  6. Check your email and click the verification link

Configure Git with Your Details

Tell Git who you are (this labels your changes). Replace with your actual name and email:

git config --global user.name "Your Name"
🔍 What this does

This tells Git your name, so when you make changes they're labeled with who made them. Replace "Your Name" with your actual name.

git config --global user.email "your.email@example.com"
🔍 What this does

This sets your email for Git. Use the same email you used for GitHub. Replace the example with your actual email.

💡 Already have a GitHub account?

Great! Just make sure you've run the two git config commands above with the email associated with your GitHub account.

🔧

Troubleshooting - Click if you have issues

❌ "Please tell me who you are" error later
Solution: You forgot to configure Git. Run the two git config commands above.
❌ Can't remember if I configured Git
Solution: Check your current settings:
git config --global --list

This shows your current Git configuration. Look for user.name and user.email.

❌ GitHub asking for username/password when cloning
Solution: GitHub now uses "Personal Access Tokens" instead of passwords. When asked for a password, use a token instead. Create one at: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token

Install Dependencies

Now we need to install all the packages the website needs to run.

🔍 What are dependencies?

Modern websites are built using many pre-made building blocks (like Lego pieces). These are called "dependencies" or "packages". This step downloads all those building blocks so your website can work properly.

Install All Packages

npm install
🔍 What this does

npm is the Node Package Manager. install tells it to download everything listed in the package.json file. This can download hundreds of small files!

$ npm install
added 523 packages in 45s
145 packages are looking for funding
run `npm fund` for details
⏳ Please Wait - This Takes Time!

This step can take 2-10 minutes depending on your internet speed. You'll see lots of text scrolling by - that's normal! Wait until you see the command prompt again before continuing.

💡 "Vulnerabilities" warnings are usually OK

You might see warnings about "vulnerabilities". For a development website, these are usually not a concern. They're warnings about the development tools, not your actual website.

🔧

Troubleshooting - Click if you have issues

❌ "EACCES: permission denied" error
Solution (Mac/Linux): Use sudo to run with administrator privileges:
sudo npm install
🔐 About sudo

sudo runs commands as an administrator. You'll need to enter your computer password. Use it when you see "permission denied" errors.

❌ "npm ERR! network" or timeout errors
Solution: Your internet connection might be slow or interrupted. Try again:
npm cache clean --force && npm install
❌ "npm ERR! code ENOENT - no such file or directory"
Solution: You're probably not in the right folder. Make sure you're inside the website folder:
cd ~/Documents/TailoredSolutions && npm install
❌ "gyp ERR!" or "node-gyp" errors
Solution: Some packages need to be compiled. On Mac, make sure Xcode tools are installed:
xcode-select --install

On Windows, you might need to install Windows Build Tools. This is rare though.

❌ Stuck on "sill idealTree" or similar
Solution: npm is calculating dependencies - this can take a few minutes. Wait at least 5 minutes before assuming it's stuck. If truly frozen, press Ctrl + C and try again.
❌ "ERESOLVE unable to resolve dependency tree"
Solution: There's a package version conflict. Try this:
npm install --legacy-peer-deps

Configure Your Business

Enter your business details below. This will customize the website for your company.

🔍 What happens with this information?

These details are saved in a configuration file on YOUR computer only. They customize the website with your business name, contact details, etc. You can change them anytime through the admin panel later.

Create Your Configuration File

Copy and run this command to save your settings:

cat > .env.local << 'EOF' NEXT_PUBLIC_BUSINESS_NAME="Tailored Solutions" NEXT_PUBLIC_BUSINESS_PHONE="" NEXT_PUBLIC_BUSINESS_EMAIL="" NEXT_PUBLIC_BUSINESS_LOCATION="" EOF
🔍 What this does

This creates a file called .env.local containing your business settings. The website reads this file to display your information.

On Windows, we'll create the file step by step:

echo NEXT_PUBLIC_BUSINESS_NAME="Tailored Solutions" > .env.local
echo NEXT_PUBLIC_BUSINESS_PHONE="" >> .env.local
echo NEXT_PUBLIC_BUSINESS_EMAIL="" >> .env.local
echo NEXT_PUBLIC_BUSINESS_LOCATION="" >> .env.local
🔍 What these do

Each command adds a line to your configuration file. > creates the file, >> adds to it.

💡 You can change these later!

Don't worry about getting everything perfect now. You can edit all of these settings through the admin panel at /admin once the website is running.

❌ Website loads but looks broken (no styles)

❌ "Module not found" or similar errors

❌ Can't access localhost:3000 in browser
Solutions:

  • Try a different browser

Deploy your website so anyone in the world can visit it

🎯 What We're Doing

Right now, your website only works on your computer. In this step, we'll put it on the internet so customers can visit it using your own domain name (like www.yourbusiness.com).

Choose Your Hosting Platform

We recommend Netlify - it's free, fast, and easy to use. Other options include Vercel and Railway.

📦 Option 1: Netlify (Recommended - Free)

Step 8.1: Create a Netlify Account

  1. Go to netlify.com
  2. Click "Sign up" in the top right
  3. Choose "Sign up with GitHub" (use the GitHub account you created earlier)
  4. Authorize Netlify to access your GitHub
🔍 What is Netlify?

Netlify is a free hosting service that stores your website files on powerful servers around the world. When someone visits your website, they get served files from the closest server, making it fast everywhere.

Step 8.2: Push Your Code to GitHub

First, we need to upload your website code to GitHub so Netlify can access it.

cd ~/Documents/TailoredSolutions
🔍 What this does

Navigates to your website folder.

git add .
🔍 What this does

Stages all your files for upload. The dot (.) means "all files in this folder".

git commit -m "Initial website setup"
🔍 What this does

Creates a "snapshot" of your website with a descriptive message. Think of it like saving a version of a document.

git branch -M main
🔍 What this does

Ensures your main branch is named "main" (GitHub's standard).

git remote add origin https://github.com/kartikdatla/TailoredSolutions.git
🔍 What this does

Links your local folder to your GitHub repository. Replace YOUR-USERNAME with your actual GitHub username!

⚠️ First, create the repository on GitHub!

Go to github.com/new, name it TailoredSolutions, and click "Create repository". Don't add any files - just create it empty.

git push -u origin main
🔍 What this does

Uploads all your website files to GitHub. The -u flag remembers this connection for future uploads.

Step 8.3: Connect Netlify to GitHub

  1. In Netlify, click "Add new site" → "Import an existing project"
  2. Click "Deploy with GitHub"
  3. Find and select your TailoredSolutions repository
  4. In the build settings:
    • Build command: npm run build
    • Publish directory: .next
  5. Click "Deploy site"
🔍 What happens next

Netlify will build your website (this takes 2-5 minutes). When done, you'll get a free URL like random-name-123.netlify.app. This is your live website!

✅ Automatic Updates!

Every time you push changes to GitHub, Netlify automatically rebuilds and updates your live website. No manual deployment needed!

🌐 Connect Your Own Domain Name

Now let's make your website accessible at your own domain (like www.yourbusiness.com)

You can buy one from providers like:

Step 8.4: Add Your Domain to Netlify

  1. In Netlify, go to Site settings → Domain management
  2. Click "Add custom domain"
  3. Enter your domain name (e.g., yourbusiness.com)
  4. Click "Verify" and then "Add domain"

Step 8.5: Configure DNS at Your Domain Provider

You need to point your domain to Netlify's servers. This is done through DNS settings at wherever you bought your domain.

🔍 What is DNS?

DNS (Domain Name System) is like a phone book for the internet. It tells browsers where to find your website when someone types your domain name. We need to add entries that say "this domain points to Netlify".

Option A: Use Netlify DNS (Easiest)
  1. In Netlify domain settings, click "Set up Netlify DNS"
  2. Netlify will give you nameservers like:
    • dns1.p01.nsone.net
    • dns2.p01.nsone.net
    • dns3.p01.nsone.net
    • dns4.p01.nsone.net
  3. Go to your domain provider's website
  4. Find DNS or Nameserver settings (often under "Domain Settings" or "DNS Management")
  5. Replace the existing nameservers with Netlify's nameservers
  6. Save changes
Option B: Add DNS Records Manually

If you want to keep your current DNS provider:

  1. Go to your domain provider's DNS settings
  2. Add these DNS records:
Type Name/Host Value/Target
A @ 75.2.60.5
CNAME www your-site-name.netlify.app

Replace your-site-name.netlify.app with your actual Netlify URL.

🔍 What these records mean

A Record: Points your root domain (yourbusiness.com) to Netlify's server IP address.
CNAME Record: Points the www version (www.yourbusiness.com) to your Netlify site.

Step 8.6: Enable HTTPS (Free SSL)

  1. Back in Netlify, go to Site settings → Domain management → HTTPS
  2. Click "Verify DNS configuration"
  3. Once verified, click "Provision certificate"
  4. Netlify will automatically set up a free SSL certificate
🔍 What is HTTPS/SSL?

HTTPS encrypts data between your visitors and your website. It shows a 🔒 padlock in the browser and is required for customer trust. Google also ranks HTTPS sites higher in search results.

⏱️ DNS Changes Take Time

DNS changes can take anywhere from 5 minutes to 48 hours to spread across the internet (this is called "propagation"). Usually it's done within 1-2 hours. Be patient!

You can check if your DNS has updated using: dnschecker.org

Troubleshooting - Click if you have issues

❌ Netlify build fails
Solution: Check the build logs in Netlify for specific errors. Common issues:
  • Missing dependencies: Make sure package.json has all required packages
  • Wrong Node version: Add a .nvmrc file with content 18
  • Environment variables: Add any required env vars in Netlify Site Settings → Environment Variables
❌ "git push" asks for password and fails
Solution: GitHub no longer accepts passwords. You need to use a Personal Access Token or SSH key. See Step 3 for GitHub authentication setup.
❌ Domain shows "DNS not configured" in Netlify
Solution: DNS changes take time to propagate. Wait 1-2 hours and try again. Make sure you've:
  • Added the correct DNS records at your domain provider
  • Removed any conflicting old DNS records
  • Saved your changes at the domain provider
❌ "SSL certificate provisioning failed"
Solution: This usually means DNS isn't fully propagated yet. Wait a few hours and click "Retry" in Netlify's HTTPS settings. Also check that:
  • Your domain is correctly pointing to Netlify
  • There's no CAA record blocking Let's Encrypt
❌ Website loads but shows errors
Solution: You may need to add environment variables to Netlify:
  1. Go to Netlify Site Settings → Environment Variables
  2. Add each variable from your .env.local file
  3. Trigger a new deploy: Deploys → Trigger Deploy
❌ "Permission denied" when pushing to GitHub
Solution (Mac): Use sudo if needed:
sudo git push -u origin main
❌ Can't find DNS settings at domain provider
Solution: DNS settings location varies by provider:
  • GoDaddy: My Products → Domain → DNS
  • Namecheap: Domain List → Manage → Advanced DNS
  • Porkbun: Domain Management → DNS Records
  • Google Domains: My domains → DNS

Search "[your provider] DNS settings" for specific instructions.

❌ "remote origin already exists"
Solution: Remove the old origin and add the new one:
git remote remove origin && git remote add origin https://github.com/kartikdatla/TailoredSolutions.git
